# Outdoor map suggestions

Anyone can read this repository. To suggest a change or leave a comment, sign in to GitHub and [open a map suggestion](https://github.com/nee00ooo/speedometer-map-packs/issues/new). Include the public place name, country or region, what you observed and when. If you have the OpenStreetMap node or way link, include it. Omit personal journeys, home addresses, contact details and sensitive wildlife locations. Closed testers can also send private feedback through the app’s Google Play listing.

RunRiots Studios reviews public submissions. A reviewer checks the source, date, location and any conflicts before adding an entry to `outdoor-notes.json`. Ordinary issue comments do not alter the app or its maps. Temporary information needs an expiry and a source. Authoritative park closures, local signs and patrol advice take precedence. Use a new revision when removing or correcting a note.

Each reviewed entry contains the public OSM `ref` (e.g. `way/123`), short plain-language `text`, the original GitHub `issue` number and UTC calendar dates `reviewed` and `expires` in YYYY-MM-DD format. The app checks this published file when a reader chooses **Read reviewed community notes**. An empty list means the studio has not published any current notes. Do not use this repository for private location sharing or live road incidents.
